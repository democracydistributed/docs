# Contributing to Democracy Distributed

Thanks for being here. DD is built by volunteers, and every contribution counts, from fixing a typo to adding a new city.

## How to propose a change (no coding needed)

1. Open the page you want to change on GitHub.
2. Click the **pencil icon ✏️** ("Edit this file").
3. Make your edit in the browser.
4. At the bottom, write one line about what you changed and why, then click **Propose changes**.
5. A reviewer looks it over, may ask questions, and approves or declines it.

That's the whole process. It works like a bill: **proposed → reviewed → enacted**, with the full history kept in public.

## Review rules

- **Anyone** can propose a change.
- For now, the project lead approves changes. More reviewers will be added as the group grows.
- **Nothing is deleted, only superseded.** Outdated content is marked and replaced, never silently removed.
- Every decision to decline a change comes with a reason.

## Writing guidelines

- **Plain markdown only.** No platform-specific blocks, so the docs stay portable.
- **Cite your sources.** Any number or claim about a government links to where it came from. If we don't know something, we say so. We never estimate or invent data to fill a gap.
- **Plain language.** Write for a curious resident, not a policy expert. Explain jargon the first time you use it.
- **One topic per page.** Link to other pages instead of repeating them.

## What doesn't belong here

This repo is public, including its history. Never add:

- passwords, API keys, tokens, or server addresses
- personal contact details (other than what someone has chosen to publish)
- opinions about named individuals
